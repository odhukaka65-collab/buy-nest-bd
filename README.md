# Buy Nest BD — Android starter app

A native Android shopping-app starter built with Kotlin and Jetpack Compose.

## Open and build
1. Install Android Studio (latest stable).
2. Open this folder in Android Studio.
3. Allow Gradle sync to finish.
4. Connect an Android phone with USB debugging enabled, or start an emulator.
5. Press Run.

## Included in this first prototype
- Buy Nest BD branded home screen
- Product search
- Category filters
- Product cards and product detail screen
- Cart item counter
- Categories, Cart, and Account navigation

## Important
This is a front-end prototype. Product data is sample data stored in the app.
It does not yet include a live database, customer login, admin dashboard, order submission,
delivery tracking, payment gateway, or production security. Those need to be implemented
and connected before publishing or taking real customer orders.
